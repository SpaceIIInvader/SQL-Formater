# SQL Atelier для VS Code

Экспериментальное локальное расширение для форматирования Firebird SQL и PSQL.
Движок и INI-пресет скопированы из Windows-приложения. Исходные папки сайта
и EXE не меняются, расширение самостоятельно и не запускает EXE.

## Установка

1. В VS Code откройте Extensions (Ctrl+Shift+X).
2. В меню `…` выберите **Install from VSIX…**.
3. Укажите `dist/sql-atelier-0.1.0.vsix` из этой папки.
4. Откройте `.sql` и проверьте, что язык документа — **SQL**.

Расширение не публикуется в Marketplace и не требует учётной записи.

## Форматирование

В палитре Ctrl+Shift+P доступны команды **SQL Atelier: Форматировать SQL**
и **SQL Atelier: Предпросмотр форматирования**. Они также есть в контекстном
меню SQL-редактора. Нажатие **SQL Atelier** в строке состояния открывает меню.

Для стандартной команды **Format Document** / Shift+Alt+F выберите
**Format Document With… → Configure Default Formatter → SQL Atelier**.
Форматирование документа отменяется обычным Ctrl+Z. Файл автоматически не сохраняется.

При желании в настройках VS Code можно включить форматирование при сохранении:

```json
"[sql]": {
  "editor.defaultFormatter": "sql-atelier-local.sql-atelier",
  "editor.formatOnSave": true
}
```

Расширение само не меняет этот выбор и не включает форматирование при сохранении.
Предпросмотр открывает неизменяемые снимки исходника и результата во встроенном
окне сравнения VS Code. Исходный редактор остаётся без изменений.

## Пресет

- **SQL Atelier: Выбрать INI-пресет…** проверяет и подключает INI-файл.
- **Открыть / создать копию пресета…** открывает выбранный INI в редакторе.
  Для встроенного пресета сначала предлагает сохранить отдельную копию.
- **Использовать встроенный пресет** отменяет выбор внешнего INI.
- После сохранения изменений INI следующее форматирование читает их заново.

Настройки **SQL Atelier**:

| Настройка | Значение |
|---|---|
| `sqlAtelier.presetPath` | Абсолютный путь, URI или путь относительно папки проекта; пусто — встроенный |
| `sqlAtelier.caseMode` | `preset`, `preserve`, `lower`, `upper`, `title` |
| `sqlAtelier.emptyLinesNumber` | `null` — из INI; `0` — не добавлять; `1` — одна пустая строка |

В проекте выбор INI сохраняется в настройках его папки; без открытого проекта —
в пользовательских настройках VS Code. В multi-root workspace используется папка
открытого SQL-файла. Относительный путь требует открытой папки проекта.
INI читается как UTF-8, UTF-16 с BOM или Windows-1251 при невалидном UTF-8.

## Ограничения

Поддерживается часть правил IBExpert; полного совпадения с ним нет.
SQL не выполняется, не компилируется в БД и не отправляется в сеть.
Ошибки форматирования оставляют исходный документ без изменений.
Обрабатывается весь документ; форматирование произвольного выделения и пакетная
обработка папки в этой версии не реализованы. Графического редактора INI пока нет.
Переносы строк документа сохраняются, содержимое SQL-литералов и комментариев — тоже.
Лимиты: 2 млн символов SQL, 60 000 символов INI, 15 секунд на форматирование.
Форматирование выполняется в отдельном Node.js worker, чтобы не блокировать редактор.
Это расширение для настольного VS Code; браузерная версия VS Code не поддерживается.

## Разработка и проверки

Откройте **эту папку** в VS Code и нажмите F5 для отдельного окна Extension Development Host.
Для тестов достаточно Node.js, внешние npm-зависимости не нужны:

```powershell
node tests/run.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1
```

Структура:

```text
extension.cjs        Точка входа VS Code
lib/                 Команды, настройки, предпросмотр и worker
vendor/formatter.js   Независимая копия движка
presets/             Независимая копия INI
tests/               Проверки движка и расширения
scripts/package.ps1  Сборка локального VSIX без скачивания зависимостей
dist/                Готовый установочный VSIX
```

Сборщик создаёт минимальный VSIX с исходниками CommonJS и метаданными. Для будущей
публикации в Marketplace можно использовать официальный `@vscode/vsce` после
выбора лицензии и регистрации издателя. Текущая сборка предназначена для локального тестирования.
