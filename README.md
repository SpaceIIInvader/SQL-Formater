# SQL-Formater
Форматирует sql запросы

SQL ATELIER — ФОРМАТТЕР SQL

ДЛЯ РАБОТЫ
Запустите SQLAtelier.exe в этой папке.
Настройки автоматически сохраняются рядом: SQLAtelier.settings.json.
Оставляйте EXE и файл настроек вместе.
Файл настроек .json.bak, если появится, — предыдущая версия настроек.

ЧТО В КАКОЙ ПАПКЕ

Документация
  Инструкция Windows.txt — работа с EXE, настройки и резервные копии SQL.
  Инструкция браузера.txt — необязательная браузерная версия.

Пресеты
  preset_ibeexpert.ini — ваш пресет форматирования.
  Его копия уже встроена в EXE. Чтобы применить изменения в этом файле,
  выберите его кнопкой «Загрузить INI» в приложении.

Исходники
  Windows — исходный код оконного приложения на C#.
  Ядро — форматтер SQL и обработка файлов, общие для приложения и тестов.
  Браузер — интерфейс прежней браузерной версии и локальный сервер.

Сборка
  build-desktop.ps1 — сборка EXE из исходного кода.
  node.gz — встроенный движок в сжатом виде.
  BuildInfo.cs — автоматически создаваемые сведения о сборке.
  SQLAtelier.build.exe, если появится, — результат последней сборки.
  Для сборки нужен установленный Node.js и .NET Framework C# Compiler.
  Выполняйте скрипт PowerShell из папки «Сборка». Путь с пробелами
  заключайте в кавычки. Результат обновляет SQLAtelier.exe в корне.

Тесты
  test.cjs — проверки форматтера.
  test-desktop.cjs — проверки пакетной обработки и резервных копий.
  Отчёты — результаты проверок приложения.
  Для запуска тестов нужен Node.js. Из папки «Тесты»:
    node test.cjs
    node test-desktop.cjs

Лицензии
  Лицензии встроенного Node.js и его компонентов.

Архив
  Предыдущая версия EXE. Для обычной работы используйте EXE в корне.

Для обычного запуска не нужны Node.js, браузер или инструменты сборки.
Все операции с SQL выполняются локально. При сохранении копии исходников
создаются в .sql-atelier-backup внутри выбранной папки с SQL.
