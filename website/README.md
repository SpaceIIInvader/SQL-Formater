# SQL Atelier — сайт

Эта папка содержит всё для браузерной версии. Её можно скопировать отдельно.

Откройте `index.html` в браузере. SQL обрабатывается локально.
Вставьте код или откройте SQL-файл, выберите INI-пресет и нажмите
«Форматировать» / Ctrl+Enter. Результат можно скопировать или скачать.

При установленном Node.js из этой папки можно запустить локальный сервер:

```powershell
node server.cjs
```

Адрес: http://127.0.0.1:8765. Остановка — Ctrl+C.

## Файлы

- `index.html`, `app.js` — интерфейс сайта.
- `formatter.js` — движок форматирования.
- `preset.js` — встроенный пресет для открытия без сервера.
- `presets/preset_ibeexpert.ini` — INI-пресет для загрузки и редактирования.
- `server.cjs` — необязательный локальный сервер.
- `docs/browser-guide.txt` — инструкция и ограничения.
- `tests/` — проверки и пример процедуры.

Проверки из этой папки:

```powershell
node tests/test.cjs
node tests/test-server.cjs
```

Проверка сервера использует свободный порт 8765.

Для публикации сохраните структуру файлов внутри этой папки.
Node.js нужен только для локального сервера и тестов.
