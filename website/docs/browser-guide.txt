SQL Atelier — локальный форматтер Firebird SQL

ЗАПУСК
Откройте index.html из папки website двойным щелчком. Интернет, сервер и установка библиотек не нужны.
Для переноса сайта скопируйте папку website целиком. Приложение Windows не требуется.

Дополнительный вариант через локальный сервер (если установлен Node.js):
Из папки website:
  node server.cjs
Затем откройте http://127.0.0.1:8765 . Остановка сервера — Ctrl+C.

РАБОТА
1. Нажмите «Открыть SQL» или вставьте скрипт слева.
2. Приложенный preset_ibeexpert.ini встроен и активен по умолчанию.
   Кнопка «Загрузить INI» позволяет выбрать другой пресет.
3. Нажмите «Форматировать» или Ctrl+Enter.
4. Скопируйте результат или скачайте .formatted.sql.
   Исходный файл автоматически не перезаписывается.

Секция «Пресет и настройки» позволяет изменить INI и нажать «Применить INI».
Для файлов Windows-1251 сначала выберите кодировку в настройках.
Скачиваемый SQL всегда имеет кодировку UTF-8; переносы CRLF включены по умолчанию.
При недоступном буфере обмена приложение выделит результат для Ctrl+C.

ПОДДЕРЖКА ПРЕСЕТА
Форматтер использует собственное ядро; это не движок IBExpert.
Поддерживается часть параметров INI: отступы блоков и параметров процедур,
регистр, запятые в списках SELECT/ORDER BY/GROUP BY/UPDATE, основные переносы
SELECT/INSERT/UPDATE/DELETE, условия WHERE/JOIN, пустые строки и пробелы.
Неподдерживаемые параметры перечислены в интерфейсе и не применяются.
Точного совпадения со всеми правилами IBExpert нет, особенно для сложных
WITH/MERGE/EXECUTE STATEMENT и вложенных подзапросов.
RightMargin — мягкий предел: длинные строковые литералы не разрываются.

General.EmptyLinesNumber задаёт число пустых строк между операторами тела:
запросами и вызовами процедур, перед проверками IF, между проверками,
между проверкой и присваиванием, между присваиванием и запросом.
Во встроенном пресете стоит 1; 0 отключает добавление пустых строк.
Серия DECLARE и серия присваиваний остаются без дополнительных пустых строк.
Перед закрывающим END и финальным SUSPEND лишние пустые строки не вставляются.
Точка с запятой внутри строки или комментария не считается терминатором.
Комментарий на той же строке остаётся с предыдущим оператором; пустые
строки добавляются после него. В конце файла пустые строки не добавляются.
KeepEmptyLines отдельно управляет сохранением уже имеющихся пустых строк.
Для ранее сохранённого INI задайте EmptyLinesNumber=1 в настройках пресета.

ДОПОЛНЕННЫЕ ПРАВИЛА ПРЕСЕТА
InputOutput.AlignTypeDefinitions выравнивает типы входных параметров
и RETURNS по самому длинному имени в каждом списке. При 0 выравнивания нет.
DeclareSection.AlignTypeDefinitions выравнивает типы DECLARE VARIABLE
внутри одной секции объявлений. Имена, типы, строки и комментарии не меняются.
DeclareSection.CRLFBeforeSELECT и IndentBeforeSELECT управляют переносом
и отступом SELECT в DECLARE CURSOR FOR (...), а не обычными запросами тела.
Insert.CRLFAfterMatching распознаётся в написании приложенного INI;
имена параметров сопоставляются без учёта регистра букв.
Insert.IndentBeforeMATCHINGColumns задаёт отступ продолжения списка MATCHING.
IndentBeforeRETURNINGColumns в Insert, Update и Delete задаёт отступ
RETURNING при переносе после ключевого слова или между элементами.
Для переноса каждого элемента включите OneReturningColumnInLine.
IfThenElse.CRLFBeforeAND/CRLFAfterAND/CRLFBeforeOR/CRLFAfterOR действуют
на внешнем уровне условия IF, в том числе внутри его внешних скобок.
AND в BETWEEN не разрывается. Case.IndentBeforeTHENExpression задаёт
отступ выражения после переноса THEN/ELSE при CRLFAfterTHEN=1.
Эти настройки работают в браузере и приложении Windows.
Полного совпадения с IBExpert пока нет: например, EXISTS может разбиваться
на большее число строк. Если CRLFAfterAND=1 в IfThenElse, условия IF
переносятся после AND, даже если исходник был записан в одну строку.

Нумерация регистра в приложении: 0 — сохранить, 1 — нижний, 2 — верхний,
3 — с заглавной буквы. Если ваша версия IBExpert использует другую нумерацию,
выберите регистр вручную. Числовая нумерация INI не подтверждена документацией.
Общий принцип INI-параметров описан в документации IBExpert:
https://ibexpert.com/docu/doku.php?id=02-ibexpert:02-07-ibexpert-options-menu:code-formatting-options

ПРОВЕРКИ
Перед выдачей результата сравнивается последовательность SQL-токенов.
Разрешаются только изменения регистра некавыченных слов и пробельных символов.
Строки, идентификаторы в кавычках, комментарии и SET TERM сохраняются.
При незакрытых скобках, строках или комментариях выводится ошибка.
Это не синтаксический анализатор всех версий Firebird и не компиляция в БД.
SQL не выполняется и не передаётся по сети. Исходники локальны.

Автоматические проверки (Node.js), из папки website:
  node "tests\test.cjs"
Проверка также на вашем файле:
  node tests/test.cjs "C:\путь\package.sql"

server.cjs — необязательный локальный сервер
